# CSS-Animation
CSS animation project exploring transitions, keyframes, transforms and interactive hover effects using HTML and CSS.
# CSS Animation Showcase

## About This Project

This project is part of my software and web development course. I'm using it to practise CSS animations and explore how movement and transitions can make a website feel more interactive.

The aim is to build a small collection of animations using HTML and CSS, without relying on JavaScript.

## What I'm Working On

- **CSS transitions** – creating smooth changes when hovering over buttons and other elements.
- **Keyframe animations** – using `@keyframes` to control movement and changes over time.
- **Transforms** – experimenting with rotation, scaling and positioning.
- **Hover effects** – adding simple interactions to make elements feel more responsive.
- **Animation timing** – testing different durations, delays and easing effects.
- **Responsive design** – making sure the project works on different screen sizes.

## Technologies Used

- HTML5
- CSS3

## What I've Learned

This project gives me the chance to put the CSS concepts I've learned into practice, experiment with different animation techniques and understand how they work together.

I'll continue adding to the project as I develop my skills and try out new ideas.

## How to View the Project

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Explore the different animations and hover effects.
